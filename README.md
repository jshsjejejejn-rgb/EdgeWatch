# EdgeWatch

EdgeWatch is a modular network visibility and security platform that provides real-time device tracking, anomaly detection, and intelligent event monitoring for local and enterprise networks.

## Features
- Real-time device scanning
- Network monitoring
- Anomaly detection
- Event logging system

## Tech Stack
- Python (Core engine + API)
- JavaScript (Dashboard)
- HTML/CSS (UI)
- SQLite (Database)
